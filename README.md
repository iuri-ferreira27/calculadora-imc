# 🏋️ Calculadora de IMC

Aplicação web para calcular o **Índice de Massa Corporal (IMC)** com base no peso e altura informados pelo usuário.

## 📸 Funcionalidades

- Cálculo instantâneo do IMC
- Classificação por categoria (Abaixo do peso, Normal, Sobrepeso, Obesidade)
- Indicador visual com escala de cores
- Dica personalizada para cada faixa
- Design responsivo — funciona no celular e no computador
- Tecla Enter para calcular

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (variáveis CSS, animações)
- JavaScript puro (Vanilla JS)

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/iuri-ferreira27/calculadora-imc.git
   ```

2. Entre na pasta do projeto:
   ```bash
   cd calculadora-imc
   ```

3. Abra o arquivo `index.html` no seu navegador — é só dar dois cliques no arquivo!

> Não precisa instalar nada. O projeto não usa bibliotecas externas (exceto a fonte do Google Fonts).

## 📐 Fórmula do IMC

```
IMC = peso (kg) ÷ altura² (m)
```

| IMC         | Classificação       |
|-------------|---------------------|
| < 18,5      | Abaixo do peso      |
| 18,5 – 24,9 | Peso normal         |
| 25 – 29,9   | Sobrepeso           |
| 30 – 34,9   | Obesidade grau I    |
| ≥ 35        | Obesidade grau II+  |
